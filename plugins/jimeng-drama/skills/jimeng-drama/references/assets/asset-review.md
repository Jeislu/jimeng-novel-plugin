# 资产图检查与修法

角色、场景、道具、分镜图出完后看一遍；用户说某张图"不像""有问题"时照第 2 节修。

## 1. 出完图看什么

逐张看，把明显的问题各写一句（哪张、在哪、是什么）告诉用户，修不修由用户定，不自己重生。看不了图就直说没看，不假装看过。值得提的：

- 角色：中间正面画出了头或第二张脸；三个展示不是同一人（发型、服装、配饰对不上）；裁头裁脚；年龄、服装、身份标记和 `## 设定` 对不上；和易混角色长得太像。
- 场景：画面里有人；有上文没写的字、乱码或品牌（视频会照着画）；锚点物缺了或数量位置不对；版本和母版不像同一个空间；可开关的陈设（灯、屏幕、门窗、舱罩）的状态和 `## 设定` 的默认初始状态不一致（视频里文字关不掉图里亮着的灯）。
- 道具：不止一件、颜色材质形制和描述对不上。分镜图：格数行列不对、人物和参考图不是同一人。
- 同一个问题在好几张图上都有，是模板或模型的问题：一起说，建议改模板或换模型，不逐张修。

整批角色图、场景图交付后，下一步要拆分镜时，说明这些图将用作参考。用户还没决定是否采用这批图时，按 SKILL.md「授权与阶段交付」发起选择，给「用这批资产拆分镜」和「先修改指定资产」两个选项。用户已要求直接推进时，交付时说清下一步并继续。当前只要资产图时，交付即可。

## 2. 修法

修图都在原来的卡和节点上做：用同一个 key 改 prompt 后重新 `node run`，不新建小节、不新建节点；被替换的图由 `--out` 自动移进 `old/`，修定后把最终 prompt 写回原 `## 小节`，让 md、卡和定稿图一致。

- 默认改 prompt 重生。先查 prompt：电影类词、否定句、条件句、混写语汇、主体段写了布局，不修 prompt 重生只是重抽。
- 用户要求在原图上改（只动一处、其余保持）时才点改：挂这张图作参考（`--ref 原图=file:cast/<名>.png`，卡不能引用自己，所以挂本地文件），prompt 只写要改的那一处："以参考图为准，保持构图、人物长相、服装、光线方向与配色完全不变，只修改：{位置与要改成的样子}。"点改结果仍落在原卡上。`--ref` 会整体替换卡上原有的参考，变体卡、版本卡要把基础造型或母版的参考一起再挂上；改 prompt 重生不传 `--ref`，原参考保留。
- 局部小毛病（多余配饰、场景里的人影、乱码）重生容易引出别的变化，可以向用户提一句"也能在原图上点改"，由用户选。
- 要改画风（太写实、太暗）时不挂旧图作参考，旧图画风会和脸一起被锁住；想保住的长相写进主体段，接受脸有小幅变化。
- 同一缺陷重生两次不过，把缺陷和选项（换模型、改描述、原图上点改、接受）告诉用户。

| 缺陷 | 重生时改什么 | 用户要原图上改时的点改句 |
|---|---|---|
| 中间画出了头、脸或头发；第二张脸 | 主体段删掉写中间展示五官、发型的句子；两次不过换模型 | 中间展示的领口是空的开口，领口上方是连续灰底，头部只属于左右两个展示 |
| 中间领口里露出人台的颈部、支架或肤色 | 同一模型多张都这样就换参考一致性更好的模型 | 领口里只看得到后领内侧的织物 |
| 裁脚裁头贴边 | 主体段压到下限（写实约 250 字、漫剧约 150 字），太长会挤掉布局遵循 | — |
| 三个展示不是同一人 | 主体段把发型、服装、配饰写成一处、不分展示描述 | 以另两个展示为准改不一致的那个 |
| AI 塑料感 | 主体段补材质：皮肤毛孔和不均肤色、布料织纹折痕、发丝分股 | 皮肤补毛孔和不均肤色，布料补织纹折痕，发丝分股补碎发 |
| 不像人设 | 核对 `## 设定` 和主体段写清没有，补写 | — |
| 易混角色撞脸 | 加大骨相和发型差异，改 `## 设定` 后只重生后做的那个 | — |
| 画风漂移 | 查首尾媒介句和语汇混写 | — |
| 上文没写的字、乱码、品牌 | 主体段把那件陈设写成无字形态（熄灭的屏、纯色块、素面边框） | 把{位置}的字改成空白平整表面 |
| 墙纸感正面平视 | 删掉"正对""对称"之类的词（原因见 `scene-plate.md` 第 1 节） | — |
| 双重阴影 | 主体段只留一个光源技术句 | — |
| 黑边、装裱边 | 删电影类词 | 把边缘补成空间延续 |
| 反打成镜像 | 强调"视点背后那面墙成为主体"；两次不过改用母版的不同局部 | — |
| 分镜格叠成上下或格中分格 | 写明"左右并排成一行"，删掉末尾追加的规则（原因见 `props-and-storyboard-image.md`） | — |
