# 场景参考图

场景图 prompt 怎么写：母版、版本、反打。设定写在 `cast/<场景>.md` 的 `## 设定`，每个版本一个小节，母版叫 `## 默认`（主时段写进主体段），其他版本按时段或状态命名（`## 夜`），定稿图 `cast/<场景>.<版本>.png`。画布上母版的卡就叫场景名，其他版本叫「场景名·版本」。图直接生成在场景卡上：`project.py canvas push` 已按 key `cast/<场景>.<版本>` 建好卡，`node update` 用同一个 key 带 `--model`、`--prompt-file cast/<场景>.md#<版本>`（缺卡时先推送场景设定），再 `node run --out cast/`。

## 1. 默认形态

单图，3/4 斜角看到相邻两面墙，纯空镜，三层纵深，1–2 个锚点物，单一主光源。正面平视像墙纸，模型读不出体积、画面外每次重编；3/4 视角能推出大部分机位。锚点物负责调度："站在落地灯旁、面向门"能稳定复现。

先出 16:9 母版定空间：竖幅会把两面墙和纵深压成走廊。竖屏片也直接挂这张 16:9 图，不另出竖版。关键陈设的数量和位置同时写进分镜的持续状态清单。

用户点名的核心地点哪怕只有一段也出场景图，并进同一批报价，只靠文字常拍成别处。模型用 `model list` / `model describe` 挑空间结构稳定的，写进 README.md，所有场景同一个。

## 2. 主体段（约 200–350 字）

风格句开头（拼装见 `references/shots/prompt-anatomy.md`），依次写：时段与主光源技术句（`style-system.md` 第 6 节）；空间结构、尺度，墙地顶写"材料 + 表面处理 + 现在的样子"；锚点物原文；2–3 件年代器物；在用痕迹；本版本的状态；末句重申媒介。

不写人物（连"没有人"也不写，空镜交给布局段）、交互小道具、器材、电影类词、氛围词、正在发生的事（酒在流）；持续状态（炭火、烛光、雾气、积水）可以写。

场景图里的字非必要不出：剧情或辨认地点需要的招牌、门牌（2–4 个字的短词）写进主体段，用【】括住原文；其余带字的陈设（标语、海报、电子屏、价签）和设备品牌写成无字形态，规则见 `shots/video-prompt.md`「画内文字」。视频会按字面继承图里的字。场景名、地名、机构名只放在标题和 key 上，主体段不写这些专名，写进去模型常把它画成招牌或墙字。

## 3. 固定布局段：直接用模板

剧本解析写回时已按媒介建好 `cast/<场景>.md`，主体段和其他时段版本写进 `project.py todo` 的清单，`project.py fill` 拼成版本小节（`asset-extraction.md` 第 9 节）。手工新建时按媒介复制 `templates/cast-scene.photoreal.md`、`.anime2d.md` 或 `.cg3d.md` 成 `cast/<场景>.md`，用编辑工具填 `<< >>`。两种做法固定段都一字不改。模板里是 16:9 母版 `## 默认`。变体：

- 室外开阔场景：保留【满幅边缘】，"两面墙"改成"两组相邻的建筑立面或地形面"，远景写山体、天际线或街道尽头。

## 4. 母版与版本

先做母版 `## 默认`：最干净、软装最少的版本，通常是白天。其他版本挂母版定稿图（`--ref <别名>=node:cast/<场景>.默认` 或 `file:cast/<场景>.默认.png`），不挂日夜两版会成两个房间；prompt = 风格句 + 母版句或换光句（见 `references/shots/prompt-anatomy.md` 第 3 节）+ 本版本完整主体段（光和状态按本版本）+ 布局段。群演不进场景图。

## 5. 反打与特殊视角

写完分镜后按机位朝向过一遍：每个镜头背后的空间都要在某张场景图里看得到，母版拍不到的方向，模型每段各编一个背景。正反打、拍向母版视点背后、调度横跨空间两端就出反打；高处俯拍、窗外望进来这类母版推不出的视角也单独出一版，主体段写明视点位置。都以母版为参考（`--ref <场景名>=file:cast/<场景>.默认.png`），记为新版本（如 `## 夜·反打`）。prompt = 风格句 + `templates/scene-reverse.txt` 的反打段（特殊视角改写成那个视点）+ 本版本主体段（视点位置、这一侧的墙和陈设）+ 所选场景模板里的【满幅边缘】【光与表面】【空间常态】。

反打的头号失败是左右镜像：主背景墙要换成另一面墙，不写"左右互换"这类词。光按空间写不按画面写：只锁光源在房间里的位置（同一扇窗、同一盏灯），照抄母版的「光从画面左侧来」会画成镜像或光反向。反打的时段和色调写在它自己的主体段。

多视图组合（母版、反打、俯视、顶视拼 2×2）约 4 倍成本且细节常被重画，用户明确要求才做。顶视图的判据：只看到顶面、没有灭点，大件陈设相对位置和母版一致，仍有材质光影，不是线框图。
