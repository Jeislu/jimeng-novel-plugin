# 角色设定图

角色设定图 prompt 怎么写：版式、主体段、造型变体、群像。固定段原文在 `templates/cast-character.<媒介>.md`，本文件讲怎么用。

## 1. 落地形态

- `cast/<角色>.md`：`## 设定` 是外观唯一来源，不提交（写法见 `asset-extraction.md`）；每个造型一个小节（`## 默认`），正文是原样提交的完整 prompt。定稿图 `cast/<角色>.<造型>.png`。图直接生成在角色卡上：`project.py canvas push` 已按 key `cast/<角色>.<造型>` 建好卡，再 `jimeng-novel node update --key cast/<角色>.<造型> --model <id> --prompt-file cast/<角色>.md#<造型> --param ratio=16:9 --param count=1`（缺卡时先推送角色设定），`node run` 时 `--out cast/` 落到上面的路径。片段视频引用角色时可以写 `--ref <角色>=node:cast/<角色>.<造型>`。修图也在这张卡上重跑（`asset-review.md` 第 2 节），修定后把最终 prompt 写回 `## <造型>`，不另开小节。
- 模型默认用「智能图片V2.5 Pro」（`gpt_image_2_5_sunburst`，支持 16:9、最多 16 张参考图）。用户指定了别的，或它不可用、同一缺陷反复出现时，再用 `jimeng-novel model list` / `model describe` 挑参考一致性和质感好的，要支持 16:9（或最接近的横幅）和图片参考，换了先出一张小样。选定写进 README.md，全项目角色图用同一个，否则画风和脸型在角色间跳。第一张先按 `asset-review.md` 看中间正面是否真的没有头。

## 2. 两种版式

无头三视图（默认）做视频的身份参考：左侧是正面看镜头的头肩肖像，全图唯一的一张脸；中间是隐形人台手法的正面着装身体，衣服撑出身形，领口空着、不画头；右侧是背面全身。清晰全脸（clearface）给用户要看全身带脸、宣传时用。默认这样画的原因：
1. 视频模型按字面读参考图。一张图里有两张脸，模型会在两者之间摇摆，身份就会漂。
2. 宽画布里全身像的脸只有几十个像素，会被当成身份来源拷进远景，越拷越糊。给全身像的脸打码也不稳：糊过的脸仍然是一张脸，还常画成光板假人头。中间不画头，脸只可能来自左侧肖像，肖像够大、五官清楚。
3. 肖像管五官，正面管体型、服装、站姿，背面管发型后部和服装背面，三个展示分工不打架。

非人角色（说话的动物、机器人、精怪本相这类不是人形穿衣的）用正面、侧面、背面三视图，三个展示都画头：它们没有衣服可撑，无头人台画不成立；身份靠轮廓、毛色和标志，侧面最能看出体型。模板是 `templates/cast-creature.<媒介>.md`。剧本解析写回建的是人形模板，`project.py todo` 清单里把这个角色的「非人」填 true，fill 会换成非人模板；人形的妖、神、拟人角色照人物做。会说话的照样有音色，进角色卡。

## 3. prompt 组成

按顺序写进造型小节：

```
[资产风格句]   README.md 里的资产风格句，没有就用风格句
[主体段]       每个造型各写一段（第 4 节）
[固定布局段]   模板原文，按版式
[光与表面段]   模板原文，按媒介三选一
[身份标记段]   模板原文，有标记才加
```

通用拼装规则见 `references/shots/prompt-anatomy.md`。布局只靠固定段，内容只靠主体段：主体段写布局、底色、分格、机位会和固定段打架；固定段改写后布局遵循会变差。固定段里有少量否定措辞是有意的：同一要求写两遍并给出可接受形态，模型才会听。主体段仍然用肯定句，否定句会召回实体。

## 4. 主体段（约 250–380 字）

从 `## 设定` 取材，按顺序写成一段：

1. 外表年龄、性别、身高体型；族裔与肤色。
2. 骨相：3–4 组相对比较。
3. 五官：眉、眼（瞳色）、鼻、唇；神态中性，双唇自然闭合，目光平视。
4. 微观质感：按下表挑 2–3 处。
5. 量化的不对称：2 处，至少 1 处带量，如"左侧眉弓比右侧高出约一根眉毛的宽度"。完全对称的脸是 AI 感的主要来源。
6. 发型：分股、碎发、鬓角。
7. 身份标记：解剖坐标，与 `## 设定` 一致。
8. 服装从上到下：形制、面料、颜色、工艺、折痕；配饰挂在身上；鞋。辨识细节（`asset-extraction.md` 第 3 节）照 `## 设定` 写在所在部位，具体到颜色、材质、位置，一个细节一句。
9. 末句用肯定句重申媒介，如"整张画面是真人实拍的写实照片质感"。

漫剧（anime2d / cg3d）主体段不写第 2 项的骨相比较和第 5 项的量化不对称，脸写成一句脸型轮廓加五官特征（眼型、眉形、标志点），篇幅压到 150–250 字。这两项是写实的去 AI 感手段，写进动漫角色会把画风拉向厚涂概念原画。

| 项目 | 写实（photoreal） | 漫剧（anime2d / cg3d） |
|---|---|---|
| 皮肤 | `[部位]+[纹理]+[光学状态]`：鼻翼两侧可辨的细密毛孔；鼻梁与额头中央一小片自然皮脂光泽，其余哑光；颧骨和耳廓边缘透出淡红 | 肤色平涂（cg3d 写柔和透光），一层硬边阴影落在下颌与颈部 |
| 毛发 | 发际线与鬓角几缕更细软的碎发单独出锋，眉毛逐根可辨 | 发束分组勾线，带状高光，发梢尖锐出锋 |
| 布料 | 可见织纹，随肘膝弯折出柔和折痕，领口轻微起毛 | 衣褶用简洁的线概括，折叠处一层阴影色块 |
| 眼睛 | 双眼虹膜同色，自然的眼神反光 | 瞳孔分层上色，一处高光点 |

风格句或主体段已经带了妆面、胭脂这类脸上的红，皮肤就不再写局部泛红：两处红叠在脸上，会画成浓重的腮红。

非人角色的主体段（约 150–250 字）按这个顺序：物种或构造；体型和尺寸（和人或常见物比）；毛色花纹或表面材质与颜色；头部和面部（眼睛颜色形状、耳、嘴）；四肢、翅膀、尾巴；身上戴着的东西；身份标记；末句重申媒介。不写骨相比较和量化不对称。

主体段不写背景、光源（光在光与表面段）、表情、动作、手持物、临时状态（泪、汗、伤、乱发）：设定图是之后每个镜头的身份来源，临时状态会被拷进所有镜头。也不写真人明星、公众人物的名字或"长得像某某"。会被取下当剧情道具的配饰（簪、玉佩、戒指）不画进基础形象，否则这件东西单独出镜时成片里会有两份；佩戴着的戏份多，就另做一个「佩戴」造型。

## 5. 固定段：直接用模板

剧本解析写回时已按媒介建好 `cast/<角色>.md`，主体段、身份标记、变体的变化短语写进 `project.py todo` 的清单，`project.py fill` 拼成造型小节（`asset-extraction.md` 第 9 节）。手工新建时按媒介复制 `templates/cast-character.photoreal.md`、`.anime2d.md` 或 `.cg3d.md` 成 `cast/<角色>.md`，用编辑工具把 `<< >>` 换成内容。两种做法固定段都一字不改。光与表面段已按媒介换好；2D 版的灰底是 `#8f8f91`，深灰底会把明亮的动画配色压暗，整张图偏概念原画。身份标记占位换成 `## 设定` 里的标记，一条一行；没有就删掉那一段。
- clearface：中间改成带头的正面全身，其余逐字不变。改三处：【构图与背景】里"隐形人台手法……的正面着装身体"换成"正面全身"，删掉以"中间展示采用"开头、以"只属于左右两个展示。"结尾的那一句；【正面与背面】第一句换成"中间的正面全身从头顶一直展示到鞋底，面部与左侧特写是同一张脸，袖口伸出自然的双手，裤脚或衣摆下是穿着鞋的双脚。"。拿 clearface 做视频参考，脸漂的风险更高，用之前告诉用户。

## 6. 定妆照（看脸的替代做法，不套固定段）

单人半身像，3:4 或 9:16，灰底，3/4 微侧，同一主体段加"画面是一张半身肖像"。只有一张脸，可用于确认长相、宣传或额外参考；身份参考仍用无头三视图。存为 `cast/<角色>.定妆.png`，prompt 写在 `## 定妆` 小节。

## 7. 造型变体

- prompt = 资产风格句 + 变体前缀句 + 模板里的固定段，同样出无头三视图；前缀句原文、挂哪张参考、跨年龄怎么改见 `references/shots/prompt-anatomy.md`。变化短语取 `## 设定` 里这个造型的那一行，跨年龄写幼态或老态。文件里复制 `## 默认` 整节改名为 `## <造型>`，主体段换成变体前缀句，固定段不动。
- 生成后和基础造型并排看：身份锚点丢了告诉用户，要修只重生变体；差异只是表情、光线、小配饰就删掉这个造型，写进视频 prompt。别为修变体重生已定稿的基础造型，用过它的镜头都会失效。

## 8. 群像图

群像角色不做个人三联。一张图 2–4 个不同的人，多了分张，比例跟项目或 16:9，存为 `cast/<群体>.群像.png`。prompt 结构：风格句 + "一组{群体类型}的群像参考图：{N} 名不同个体并排站在中性纯灰无缝背景上（色值同本项目角色模板），中景全身，人物之间留有自然间距" + 群体外观白描 + "每个人的五官、身形与神态各有细微差异，是各自不同的人" + 媒介重申句。人数照要用它的镜头写。它只给造型范围，不保证个体跨镜头相同。

## 9. 照用户的图出设定图

用户给了角色的照片、插画或手稿，要照着它出角色图时，在这个角色的卡上图生：

- 用户的图已经是设定图（多视图、干净背景、全身）就直接用，不再生成，做法见 `asset-extraction.md` 第 8 节。单张照片、插画或半身像，或用户说要照它出设定图，就照本节做。
- 先照图写 `## 设定`：看得到的以图为准，看不到的（背面、鞋、身高）按角色补，和剧本冲突时告诉用户。主体段照图写，固定段照常（非人角色用非人模板）。
- prompt = 资产风格句 + 参考图起稿句（`shots/prompt-anatomy.md` 第 2 节）+ 主体段 + 固定段；更新这张角色卡时挂 `--ref <参考别名>=file:<用户的图>`。用户的图另存一份到 `cast/<角色>.参考.<扩展名>`，注明"用户提供"。
- 图里是可识别的真人时，按 SKILL.md 底线提示一句授权。
- 生成后对着原图看一遍：长相、发型、配色明显跑了就告诉用户，修法同 `asset-review.md`。定稿后这张设定图就是基础造型，变体挂它，不挂用户的原图。
