# 衔接与连续性

讲同一场戏拆成多段时怎么接上、首尾帧模式、跨集连续，以及重生成影响谁。模型看不到上一段，衔接全靠正文和参考。

## 手段，按顺序选

1. 合并：同场连续、不超上限也不超载就合成一段（见 segmenting.md），段内衔接最顺。
2. 文字承接：后一段第一个阶段先把前段最后一帧的状态具体重写（位置、绝对朝向、坐还是站、彼此间距、视线、手里的道具、身体和锚点的接触、光从哪边来），再接本段动作，挂了尾帧也要写。动作按前段结尾的进度接：已完成的只写结果，进行中的从同一阶段、同一方向接着做，还没开始的写起势和路径。
3. 尾帧参考：不默认挂，逐个接缝判断，下面三条都满足才挂：
   - 后段第一个镜头和前段最后一个镜头拍的是同一片空间，机位在轴线同一侧。后段从反打、特写或另一个方向起拍就不挂，尾帧会把对面的空间和朝向带进来。
   - 前段结尾有场景图和站位锁说不清的状态：三人以上的站位、有人躺着或被推着、打斗后道具散落、动作跨过接缝继续。两人隔着一件家具对话这类，场景图加站位锁就够。
   - 前段已经验收通过：脸、服装、道具没漂，画面里没乱码。有问题的尾帧会把问题传给后段；前段还可能重拍的，先别让后段依赖它。

   挂了也照写文字承接，正文用限定句只承接空间状态（video-prompt.md「其他参考的用法」）。限定句不一定管得住第一帧：试过的情况里，后段第一帧倾向于贴着尾帧起拍（同机位、同景别，人和道具在原位），正文要求换景别没有生效；尾帧上画错的陈设也可能压过场景图、带进整段。所以挂了尾帧时，后段第一个镜头按同机位接着拍来写更稳，接缝出片后照样要验收（`shot-review.md`「衔接」）。只写文字承接时，站位和动作进度一般能接上，躺着的人头脚朝向仍可能翻过来。代价是后段要等前段出片才能提交、占一个参考名额；人物长相仍以角色图为准，名额不够时先保角色图和场景图。
4. 尾段视频参考：连续动作要无缝（追逐、动接动）时，挂前一段最后约 3 秒，最贵最慢，只给关键段。

尾帧和尾段只用在同场景同版本、至少一个主要角色连续出现的紧邻前一段上；跨场景、空镜、闪回进出、平行剪辑挂了会把前一场的空间带进来。被依赖的段自己不靠尾帧（连续两段都靠尾帧时后一段改成文字承接），这样一集最多两轮：先并行跑不依赖别人的段，取帧后再跑衔接段。

## 怎么挂

尾帧：

```
jimeng-novel frames out/E01/S02.mp4 --at end --out out/E01/尾帧/
```

`--out` 存的是原分辨率单帧。先看一眼这张图，再把 `前段尾帧=file:<输出的 frames[].path>` 加到 `node batch` 里 E01/S03 的 `refs` 数组，保留这段已有的角色和场景参考。

尾段视频：`ffmpeg -y -v error -ss <时长-3> -i out/E01/S02.mp4 -c:v libx264 -crf 18 -c:a aac -strict -2 out/E01/S02.tail.mp4`（时长看 `frames` 的输出；重编码，`-c copy` 按关键帧切，长度不准；老版本 ffmpeg 没有 `-sseof`），再把 `前段尾段=file:out/E01/S02.tail.mp4` 加入同一段的 `refs`。参考视频的个数和时长上限看 `model describe`。

正文限定句见 video-prompt.md「其他参考的用法」。尾帧作普通参考挂：第一个镜头多半贴着尾帧构图起拍，之后的分镜照常切机位。

## 首尾帧模式

拼法见 prompt-anatomy.md 第 4 节。这个模式不挂角色和场景参考，长相全靠首帧延续，所以只用在严丝合缝的衔接（同机位延续、动接动），换场换机位仍用普通参考。正文不再描述首帧构图，第一个阶段只写站位朝向和从这一帧出发的动作，有尾帧时写走向尾帧的过程；角色不重演前段已完成的动作、不重说已说的台词。

## 切点

- 在动作完成后切，后一段从前段结尾的静止状态起拍。例外是用尾帧或尾段衔接的同场段，可以在开门、转身、起身、递物这类自然掩护点切，后一段从动作的下一阶段起拍。
- 余韵和停顿写在前一段末尾，不在后一段开头加「停顿一秒」。
- 后一段第一个镜头的景别或机位要和前段最后一个镜头有看得出的差别，同构图相接像画面跳了一下。首尾帧同机位延续、挂了尾帧（第一帧多半贴着尾帧起拍）、叙事要求固定机位、用户给定了镜头的除外。

## 同场多段：站位锁与轴线锁

同一场戏拆成多段前先定两句固定文本，逐字复制进每一段：

- 站位锁：按人物和锚点写，不按画面左右写，写全相对锚点的位置、中间隔着什么、大约多远，如「{{女主}}站在八仙桌靠窗一侧，{{男主}}在靠门一侧，两人隔桌相对，相距两步」「{{乙}}走在{{甲}}右手边」「门在{{甲}}身后」。两人以上同框的每个分镜都逐字带上，不是每段写一次；侧拍、全景再写锚点在画面里怎么摆（「办公桌从画面左下横到中间，{{女主}}在桌子远侧」），只写画面左右，「桌前、桌后」会被随意理解。锚点的方位从挂的场景图里读出来（门、窗、床头在哪面墙），不凭剧本想象；要的布局和图对不上，改站位锁或先出新版本的场景图，不靠正文去扭，文字和图冲突时模型每段随机信一边。切机位只是换角度，人物绝对位置不变。
- 躺着、坐轮椅、被抬着的人，锁头脚朝哪端、挨着哪个锚点（「头朝床边的监护仪」），每段写一次；只写「仰面躺着」，头向会在段间翻过来。
- 轴线锁：画面左右关系，如「{{女主}}在画面右侧」。只在各机位都在轴线同一侧时成立；机位转到另一侧（迎面拍换成背后跟拍，正打换反打），画面左右对调。每个分镜按这一镜的机位把站位锁换算成画面左右再写进正文。

逐段核对每个角色的银幕侧、姿态、手中道具、锚点；前段在左、后段在右又没交代走位、也不是机位换到了另一侧，就是越轴。

前一段结尾某人停在某处，后一段景别拉开（全景、后拉）拍得到那里时，要么把他写进这一拍（位置、姿态、嘴唇紧闭），要么用机位避开；正文没写的人模型就不画，会凭空消失。

## 跨场景转场

跨场景默认硬切，不挂衔接参考，但前段结尾或后段开头要有一个可见的过渡动作：离开时推门出画、镜头上摇到窗外；进入时推门进来、缓缓睁眼、镜头从新场景锚点物移到人物。声音桥只写环境声（见 dialogue-and-sound.md）。只写「画面切到另一个场景」不兑现，淡出入黑见 video-prompt.md「不兑现或有害的写法」。

## 场景、造型与处境

- 挂哪张图按 segmenting.md「其余绑定」；片段内当场换装才挂前后两张，正文分阶段说明。
- 辨识细节（asset-extraction.md 第 3 节第 3 条）是造型的一部分，交给参考图，变体没改到就继承。动作碰到它（摘下、拨弄、换手），措辞照 `## 设定` 写，之后的段按新状态写；本段新加的服饰、道具不和它冲突。
- 加减衣物（套上背心、脱掉外套）不算处境，出造型变体图：靠文字加的衣服会串到同框的另一个人身上。
- 处境类状态（伤痕血迹污渍、湿身凌乱、哭红的眼眶）不建新造型，每次出现都在正文重写，措辞全剧逐字一致（「伤疤」「划痕」混用会画成两种伤），固定措辞可记在 cast/<角色>.md 的设定里；挂了状态图时交给图，不再复写图上已有的部分（见 video-prompt.md「参考绑定与回指」）。

## 持续道具与环境

没写进本段的状态模型按默认补：同一辆车每段换样，人进了屋画面里还在下雨。

- 本段在场的持续道具：有参考图的挂图，外观交给图，正文只写本段才有的状态和位置；没参考图的每段写一次外观，措辞从顶部清单逐字复制（颜色、材质、形制、尺寸和怎么拿，如「巴掌大，单手竖握」，一个辨识细节）。印刷的颜色不用「高亮」「发光」这类词，会被画成光效。有特写、或跨三段以上出现的道具出参考图（segmenting.md「其余绑定」），只靠文字形制每段都变。段内切镜后，还看得到的关键道具重写一次状态（在不在、在谁手里、什么状态），否则会丢。
- 每段写明环境状态：室内还是室外、天气、时段（主光跟场景图走，见 video-prompt.md「结构」；没挂场景图才写光线方向），以及环境声的状态（车在行驶还是已停稳、雨在下还是停了）。环境声照上一段结束时的状态写，不整句复制前面的段（车已停下声音还在高速行驶）。场景切换后只写新状态，旧状态不再提：进屋后写「室内，窗外雨声」，不写「雨中」。
- 连在固定物上的道具（插在设备上的插头、拴着的绳子）写手和固定物怎么接触（「右手握着插在设备侧面的插头」），不写「攥着插头」，否则会画成一件拿在手里的独立物件。
- 道具状态变了（撞瘪、屏碎、被摘走）从变化那一段起改用新措辞并更新清单。段内变化写清怎么变、变成什么样（「玉镯在掌心裂成两半，两半各握在一只手里」），只写「捏碎」每镜碎法都不同。之后的段写剩下的样子（「手腕上空着，只剩一道红印」），不写「玉镯不见了」，否定句会召回旧道具。挂图见 segmenting.md「其余绑定」。

## 跨集连续

写下一集分镜前，从上一集剧本和 shots 最后一段推一张集末状态：

| 项 | 内容 |
|---|---|
| 造型 | 每个角色当前的造型（换装了没有） |
| 处境 | 伤痕、污渍、湿身、妆容，以及固定措辞 |
| 道具 | 关键道具在谁手里、什么状态（完整、撕碎、已打开） |
| 时空 | 场景版本、日夜、天气 |
| 站位 | 最后一个画面的人物位置和朝向 |
| 已知信息 | 哪些秘密已揭开、谁知道了什么，防止下一集重演或提前泄露 |

下一集第一段承接上一集钩子（同场同时刻）时，起始状态和这张表一致，可挂上一集最后一段的尾帧。同一地点在不同集再出现，沿用前一集这个地点的站位锁和轴线锁（谁通常在哪一侧），剧情没让人换位置就不换，否则同一间屋子会像镜像。

## 只重拍一段的后半

一段前半满意、后半要改时，截掉后半另起一段补拍，比整段重做便宜（只改细节、保留原画面时见 `references/post/revise.md`）。补拍段要从切点那一帧接上：

- 用 `jimeng-novel frames` 在切点导出那一帧，前半段在合成时用 `jimeng-novel compose` 的裁剪参数截出（都看 `--help`）。
- 补拍段用 `--first-frame file:<切点那一帧>`（首尾帧模式，拼装见 prompt-anatomy.md），正文第一句写这一帧的机位、景别和人物位置，再接新动作。
- 补拍是新的一批，按铁律 1 先报价；拼接后在切点前后各抽一帧对比。

## 重生成的影响

某段重生成并选用后，挂它尾帧或尾段的下一段参考就过期了：重新取帧，问用户依赖段是否重生成（付费，按铁律 1）。站位、道具状态或处境变了就同步更新站位锁和处境措辞。
