# 订阅引导

只在服务端明确拒绝时展示订阅引导，以本次实际错误为准：

- 提交错误明确表示当前空间需要会员权限才能提交短剧生成任务；
- 已确认的非会员用户实际提交生成后，提交回执或失败任务结果明确说明所用模型仅会员可用。

原因同时检查提交错误与任务结果。任务结果可能是顶层 `status=success`、`error=null`，但 `data.status=failed`、`data.error_message=仅对会员用户可用`，仍应按生成失败处理。批量结果逐项判断，不把部分失败说成全部失败。

不将登录失效、空间或素材访问权限、积分不足、网络故障或其他生成失败归为会员问题；报价非零或体验用完也不单独触发。账号状态查询失败不视为非会员。只有 `generation tool returned an error` 等通用文案时保持原因未知，不猜会员或积分问题。

停止本次受限操作，沿用以下文案。模型权限错误时填写实际模型展示名；空间准入被拒时把首句换成“当前空间暂不满足提交生成任务的会员条件”。对产品的称谓以会话上下文为准，未指定时称“即梦”：

> 本次生成未成功，当前账号暂无使用【模型名称】的权限。你可以[订阅即梦会员](https://jimeng.jianying.com/ai-tool/home?commercial_action=open_vip)，继续使用该模型创作。
>
> 即梦支持：
>
> - **图片、视频与音频创作**：通过对话生成图片、视频、配音和音乐。
> - **专业创作指导**：结合创作技巧，完成剧本、角色、场景和分镜设计。
> - **画布管理与持续编辑**：在同一画布中管理素材、查看结果，并继续修改和组合创作。
>
> [订阅即梦会员](https://jimeng.jianying.com/ai-tool/home?commercial_action=open_vip)

- 支持 Markdown 的宿主渲染为可点击链接；纯文本宿主展示同样文案与完整 URL。
- 只有错误明确表明订阅会员可解决时才使用上述订阅表述，否则只说明已知限制，不承诺订阅后一定可用。积分不足不引导为“充值就能解锁会员模型”。
- 不把错误码、排查过程或重复重试作为正文；不自动打开订阅页或替用户下单，不承诺未经确认的优惠、赠送权益或无限生成。
- 不静默替换用户指定的模型，不自动重提。用户要求换模型时，再查询目录和本次有效报价，不把目录可见或参考价当成可用证明；换模型重新报价并确认。
- 用户表示已开通后，核对 CLI 当前账号及会员状态；重新生成仍遵循原有报价、确认和防重复提交规则，不把打开购买页当作已开通。扣费按实际返回事实说明，不能仅凭失败承诺未扣费或已退款。
