# 人物小传、外观设计、场景空镜

写进 characters.md、scenes.md 对应的字段（格式见 output.md）。先通读全文、理清每个人的经历，再动笔。

## 角色

主角、重要配角、配角都要写，龙套不写。

1. **先定识别组合和痕迹**（不写进文件，写外观时用）：每个人想好两项：
   - 识别组合（不超过 40 字），包括脸型或体型轮廓、发型、服装主色，以及一件标志性的东西。
     - 全剧所有人的组合要互不相同。同性别、年龄段相近的人尤其要拉开：脸型或体型不同，发型不同，主色不同。
     - 原文写明的外形必须照原文，不能为了区分改掉。
   - 痕迹：这个人的经历、处境或性格在外形上留下的 1–2 处具体痕迹，写成「来由：痕迹」，不超过 50 字。
     - 来由是这个人自己的一段经历、一种处境或一个性格（从小传、性格词里来），不能只是身份、地位、职位。
     - 好：「常年伏案记账：袖口磨得发亮、背有些驼」「刚从牢里出来：衣服显得宽大、颧骨突出」「多年隐忍不言：嘴角习惯性抿紧、目光常垂向地面」。
     - 不好：「身为掌事：衣着整齐」「宫妃身份：满头珠翠」「性格谨慎：衣襟收束」「性格谨慎：神情审慎」。这些是谁当这个官、谁有这个性格都能写的，看不出是这个人。「整齐」「利落」「收束」「端正」「干净」不算痕迹，「神情专注」「神情审慎」「神情警觉」这类只换一个形容词的神情也不算。
     - 同一部剧里不同人的痕迹不要雷同。
     - 写进主状态的外观设计里。
2. **性别**：男、女、未知。看原文的代词（他、她）、称谓和亲属关系；推不出时写未知，不要只凭名字猜。
3. **性格**：3–5 个词，要从这个人的选择和行为里看得出来，不用谁都能套的空词。
4. **小传**：人物小传，一段话，顺序是出身背景 → 经历轨迹 → 核心驱动力。主角、重要配角 150–300 字，配角 60–150 字。
   - 只写原文明写或能直接推出的事。原文没交代的动机、来历、职业、亲属不要补。
   - 有隐藏身份或身份反转的，写出来。要写到结局。不写集数。
   - 每句话都要能在原文里找到依据；写之前把这个人出场的地方都翻一遍，不要只看前几集。
   - 小传依据：把小传里几件主要的事在原文的出处行号写进「小传依据」（主角、重要配角至少 3 个，配角至少 2 个），出身、转折、结局最好都有。
5. **每个状态**：
   - **年龄段**：幼儿、儿童、少年、青年、中年、中老年、老年，取其一。原文没写岁数时，按称谓、身份、资历、亲属关系推断。
   - **外观设计**：一段连贯的文字，不分条，不加「脸型：」这类标签。
     - 第一个状态是主状态，要写完整，80–300 字。顺序：年龄性别 → 脸型 → 发型发色 → 五官 → 身高体型 → 上装 → 下装 → 鞋 → 配饰。
     - 其他状态只写相对主状态变了的部分，比如换了装束、年纪变了，20–200 字。
     - 原文写明的外形要全部保留，不能改。包括你在「外形」里写的、不带「据身份推断」的部分。原文没写的，按时代、地域、身份和处境补全。
       - 例外：原文写的手里拿着的东西，改成佩戴或收在身上（挂在腰间、揣在怀里）；只在某一场出现的表情、动作、伤和污渍不写进常态外观。
     - 外观要带上这个人的经历和性格，但不要夸张。只从这几处体现：
       - 衣服的新旧、磨损和穿法；
       - 头发的打理；
       - 体态；
       - 平时的神情；
       - 和身份、经历有关的佩戴物；
       - 身体痕迹：原文写到的伤疤、残疾照写；手上的茧、晒黑的皮肤只给原文写明长年干粗活、常年在外的人。别的印子、勒痕、针眼、咬痕都不写。

       例：常年伏案记账的人，袖口磨得发亮，背有些驼；家道中落的人，衣服洗得发白，却穿得整整齐齐。

       痕迹要从小传里写到的长年经历、处境来，主要落在衣着、打理、体态和神情上，身体上的痕迹是少数。不要为了留痕迹编一个原文没有的习惯动作。

       至少一处要落在和这个人做的事直接相关的衣着、佩戴物或体态上，比如卖茶的腰间掖着茶巾、常年抄写的袖口磨亮。神情只能作补充；同一部剧里不同人的神情不要用同一个词。
     - 不写：
       - 背景和环境；
       - 画风词，比如写实、3D、二次元、厚涂；
       - 手里拿着的东西：兵器、包袋写成挂在腰间或背在身后；
       - 一时的动作和表情，比如大笑、流泪、出汗；
       - 脏污：衣服、鞋和手上的灰、泥、油、墨、炭粉、汗渍、茶渍，除非原文写了；
       - 残破：破口、掉扣、补丁、掉漆，除非原文写了。旧衣服写到洗得发白、磨得发亮为止；
       - 原文没写的伤疤、伤痕、伤口、残疾。
     - 性格只体现在平时的神情和体态上，神情写得平实，不用比喻和夸张的说法（「眼神如刀」不行）。不要由性格推出脸型、肤色、五官，比如「刻薄所以嘴唇薄」「多疑所以眼睛细长」不行。
     - 不用「普通」「路人脸」「清秀」这类笼统的词收尾，要落到具体的形状、颜色和材质。
     - 不写「待确认」「尚待确定」这类占位的话：原文没写的按时代、身份和处境补全，拿不准的地方写进最后的回复。
     - 每个人的脸、五官、体态、痕迹都要单独写，不要套同一串话。同一句描写脸、五官、体态或痕迹的话，在好几个人的外观里一字不差地出现，会被退回重写。

## 场景

每个场景都要写。

- **原文所见**（写进 scenes.md）：原文里写到的、空镜里看得见的东西，逐条列出，每条一个短语加行号。先写这一行，再写空镜。
  - 收这几类：空间格局（几进院、长廊、楼梯、窗朝哪边）、陈设和器物、材质和颜色、光线。人物、动作、声音、气味不收。
  - 按分场底稿，把这个场景出现的每一场都翻一遍，不要只看第一场。环境描写多在场头和紧跟着的几行（剧本里常是 △ 开头的描述行），这些行往往不出现地点名，按名字检索找不到，要按场的行段去读。
  - 子代理交回过地点记录的，以记录为底，再回原文补。
- **时段**：这个场景最常出现的时段，取清晨、白天、黄昏、夜晚之一。
- **空镜**：空镜描述，一段连贯的文字，60–250 字。顺序：时段 → 空间结构（室内还是室外、格局）→ 主要陈设 → 材质和色调 → 光线。
  - 不出现任何人物，也不写人物动作。
  - 「原文所见」里长期在那里的东西要全部写进去：空间格局、固定陈设和大件器物、材质颜色、光线。写完对着它核一遍。原文没写的，按时代、地域和这个地方的用途补全，不要堆砌，不写「待确认」这类占位的话。
  - 一时的状态和随手的小物不进空镜：门半开、碗打翻、玻璃碎了、桌上摊着的信、茶杯手机这类，留给视频。持续一段剧情的状态（被查封、婚礼布置、被砸之后）和明显的天气（雨夜）写成「其他时段」里的一条，格式同下，如「被砸之后：货架倒地，满地碎玻璃」。
  - 每个地方写自己的样子。「光线落在地面与陈设上」这类哪里都能用的句子，在好几个场景里一字不差地出现，会被退回重写。
- **其他时段**：这个场景在原文里还以别的时段出现时，每个别的时段写一条，只写那个时段的光线和明显不同的地方，不超过 60 字，如「夜晚：烛火昏暗，窗纸透出微光」。持续的状态变化也在这里写一条（见上）。都没有就不写这一行。
  - 有上级的场景，时代、材质和色调要和上级场景一致。
  - 不写画风词。
