# 输出格式

三个文件都是 Markdown，放在同一个目录里（`<剧名>/.breakdown/`），字段写成 `- 字段名：内容`，一个字段一行，不换行续写。没有内容的列表字段写「无」。文件里只有第一行的 `# 标题` 和下面这些条目、字段；说明、备注、待确认清单不写进这三个文件，写进你最后的回复（下游按字段逐行读，多出来的行会被当成格式错误）。

原文行号：原文是一个文件时写 `L12`；原文是已经分好集的剧本目录（每集一个 `E01.md`）时写 `E01:L12`，引用同目录的设定文件写 `setting:L5`。分好集的剧本不用分集，也不交 episodes.md，集号就是文件名里的集号。

## episodes.md

```markdown
# 分集

## 第1集：雨夜来客
- 原文：L1-L46
- 梗概：林秋禾在渡口茶棚收工时，陌生人留下一只木匣后离开。她打开木匣，发现里面是失踪多年的父亲的怀表。结尾，茶棚外有人喊出她的小名。
- 钩子：茶棚外有人喊出林秋禾的小名。
- 角色：林秋禾、周伯、陌生人
- 场景：南岸茶棚、南岸渡口
```

- 标题行 `## 第N集：标题`。原文有集标题时，集号和标题都照原文（原文集号跳号、重复也照抄，校验按原文核对）；没有集标题时 N 从 1 起连续编号，自拟一个短标题。
- 原文：`L起-L止`，第 1 集从 `L1` 起，最后一集到最后一行，各集首尾相接、不重叠、不留空。
- 梗概：2–4 句（按句号、问号、叹号数），见 extract.md。
- 钩子：一句话。
- 角色：这一集在场的人，用 characters.md 里的名字，`、` 分隔；某人这一集是非主状态时可以写 `名字[状态名]`。没有写「无」。
- 场景：这一集戏实际发生的地点，用 scenes.md 里的名字。

## characters.md

```markdown
# 角色

## 林秋禾
- 级别：主角
- 别名：秋禾、林家丫头
- 简介：南岸渡口茶棚的掌柜，失踪船工林远山的女儿
- 性别：女
- 性格：倔强、细心、重情义
- 小传：……
- 小传依据：L3、L18、L240、L512

### 茶棚掌柜
- 外形：二十出头；粗布短衫，围裙；据身份推断：女，青年，粗布劳作服饰
- 年龄段：青年
- 外观设计：……
- 出现：第1、2、3、5集

### 船帮学徒
- 外形：剪短头发，换男装混进船帮
- 年龄段：青年
- 外观设计：……
- 出现：第4、5集

## 周伯
- 级别：龙套
- 别名：无
- 简介：在茶棚帮工的老船工

### 主状态
- 外形：据身份推断：男，老年，旧式短打
- 出现：第1集
```

- 级别只能是：主角、重要配角、配角、龙套。
- 每人至少一个 `### 状态`，第一个是主状态；主角最多 4 个状态，其他人最多 2 个。
- 必填：级别、别名、简介；每个状态的外形、出现。
- 主角、重要配角、配角还要写：性别、性格（3–5 个词，`、` 分隔）、小传、小传依据；每个状态的年龄段、外观设计。龙套不写这些。
- 小传依据：小传里的事在原文的出处，写行号，`、` 分隔；主角、重要配角至少 3 个，配角至少 2 个。
- 出现写成 `第1、2、5集`。

## scenes.md

```markdown
# 场景

## 南岸茶棚
- 别名：茶棚
- 上级：南岸渡口
- 描述：民国江南渡口边的竹木茶棚，……
- 原文所见：竹木搭的棚子（L3）；四张矮木桌、一口铜壶（L5）；棚檐挂一盏马灯（L9、L40）；油布帘子（L41）
- 时段：夜晚
- 空镜：……
- 其他时段：白天：……；黄昏：……
- 出现：第1、2集
```

- 必填：别名、描述、原文所见、出现；没有上级就不写「上级」这一行。
- 原文所见：原文写到的、空镜里看得见的东西，每条一个短语加行号，`；` 分隔；原文一点没写就写「无」。写法见 design.md。
- 时段、空镜每个场景都写；其他时段只在这个地点还以别的时段出现时写，`时段：光线和不同之处`，多条用 `；` 分隔。
