# 抽取口径：分场、分集、角色、场景

## 1. 先分场

把全文切成首尾相接的场（叙事单元），这是你自己的底稿，不用交，分集、出场、梗概都从它来。

- 地点变了、时间明显跳了、插进另一时地的回忆、人物组合大变、一串动作断开，都要切场。一个场不跨两个独立的物理空间；从一个房间走进另一个房间要切。
- 遇到集标题必须从标题行另起一场，场不跨集；遇到章标题至少另起一场。
- 每场记下：
  - 在场的人：本场实际在场、有台词或有动作的人。只被提到的人不算；群体和泛指（众人、士兵们）不算；单个人有台词，哪怕只有称谓也算。
  - 地点：戏实际发生的那一级（房间、院子、门前），不要只记城市、整栋楼。
  - 发生了什么：一两句，写清谁做了什么、结果怎样，关键的发现、决定、交接都写进去，保留因果。不写「众人推进调查」这类空话。
  - 结尾：本场末尾实际发生的事，有没有悬念、危险、揭晓、反转或没做完的选择。不续写。

## 2. 分集

原文已经分好集（每集一个文件）时跳过这一节，场、出现集都按文件的集号。

- **原文有集标题**：每个集标题一集，集号顺序编，标题照原文。哪些行算集标题，用 `episode_heads.py` 的结果（目录、分镜表、修订记录这类集号从头再来的块，并进相邻的那一集，不另成一集）。第 1 集从 L1 起（标题前的前言并进第 1 集），最后一集到全文最后一行。
- **原文没有集标题**：用户给了集数 N 就分 N 集；没给就自己定，每集大约 3000–6000 字，最长不超过 8000 字。原文有「第X章」「第X回」时，短章合并成一集、过长的章拆开。切点放在场尾，优先放在结尾有悬念、危险、揭晓、反转的场后面；各集长短大致均衡；不要切在一场中间。
- **梗概**：2–4 句。按本集各场的顺序写清关键事件的参与者和结果，最后一句写本集结尾发生的事。
- **钩子**：一句话，写本集最后一场结尾实际发生的事。
- **角色**：本集在场的人（不是只被提到的），按在本集首次出场的顺序。
- **场景**：本集戏实际发生的地点。

## 3. 角色

### 收谁

- 收剧情里实际出场（有台词或动作）的单个人，包括没有名字、只有称谓但有台词的人。
- 不收：群体和泛指；只在对白里被提到的人；只有职能称谓（管事、守卫、司机、店员、服务员这类）而且全剧没有台词也没有动作的人。
- 名字用原文最常用的称呼，中文名优先全名。名字会用作 cast/ 的文件名和画布节点 key，不能带空格、「.」「/」：外文名用原文最常用的单个称呼（名或姓，如 John Smith 写成 John），全名写进别名。第一人称叙述者要找出原文给的名字，找不到就叫「叙述者」；不同人的「我」不能合并。

### 别名

- 原文里实际用来称呼这个人的昵称、名、姓加职务、外号，能确定是同一个人的都收，只出现一次也收。
- 只凭同姓、同职业、同一个泛称（老人、姑娘）不合并。纯称谓没有证据不要硬并到某个人名下。
- 别名必须是原文里出现过的字样。

### 级别

- **主角**：贯穿全剧的视角人物或故事的发动者，全剧 1–3 人，出场集数至少占全剧的四分之一（集数少时至少 2 集）。双主角（男女主、搭档、师徒、母女）里的第二人几乎每集都在、和第一主角一起推进主线、自己也有心结或成长线时，也是主角；只在部分段落协助或阻挠，或者以上司、长辈、对手身份出场的，出场再多也是重要配角。
- **重要配角**：多次推动关键情节的人。
- **配角**：有名有姓、有自己的戏，但不主导情节。
- **龙套**：只有职能称谓，或者只出现一两场。出场三集以上、不只是职能称谓的人至少是配角；只有职能称谓、出场却在三集以上的龙套，简介里写明「只有职能称谓」。
- 级别只按这个人在剧情里的分量定，不因为配角以上要写小传和外观就往低定。

### 简介

不超过 50 字，写原文明示的身份和关系。不能只写「医生」「工作人员」，没名字的人用地点、服务对象和实际动作区分（「在码头报修的施工员」「给某人看右手的大夫」）。

### 状态

- 第一个是主状态。主角、重要配角的主状态用简短的身份做名字（「茶棚掌柜」）；配角、龙套写「主状态」。
- 只有长期的变化才另开状态：长期伪装或化名、年龄跨越（童年和成年）、身份阶层变化带来的持续换装。临时的伤、情绪、一场换衣服不开状态。主角最多 4 个状态，重要配角最多 2 个，配角和龙套只有主状态。
- **外形**：汇总原文各处写明的、稳定可见的特征：年龄、衣着、体态、发型、拐杖面具这类随身物，逐条写全，不要只写第一处。原文没写的，在「据身份推断：」后面补性别、大致年龄段和身份服饰，不编五官、伤疤、发色。群体的描写不要挪到个人身上，表情不算外形。
- **出现**：这个人在这个状态下在场的集。

性别、性格、小传、年龄段、外观设计的写法见 `design.md`。

## 4. 场景

### 收哪些地点

- 剧情里实际演过一场戏的独立物理空间，演过一场就收。只在对白里提到、叙述里一笔带过的不收。
- 独立的房间、不同的建筑或住宅、室内和室外分开收。同一空间里的窗边、门边、桌旁、台区、操作区，以及昼夜天气的不同，不另起，写成那个空间。只是路过的通道并进相邻的地点，走廊里有完整的戏才单列。
- 住宅、店铺、机关的门前、门口、门槛外、台阶、楼前是室外，和屋里分开收（人坐在门槛上、站在门口说话的那场，地点是「门前」或「门口」）。车厢、电梯轿厢、船舱这类封闭空间里演了整场戏，也单独收（「车里」写成「车厢」）。坡道、石阶、楼梯、电梯口这类过渡空间演了完整一场戏，同样单独收，用原文的词。
- 原文只写「卧室」「厨房」「门前」「院子」，但上下文明确是哪一户、哪栋楼的：场景名写成「上级专名 + 这个词」（「陈家卧室」「陈家门前」），上级写那户人家或那栋楼。
- 没有归属的泛指空间（一间空屋、巷口、小院、河滩、屋里、路上）和器物（锅里、桌上）不单独收；这种场能确定在哪个有专名的地点时（人在某个镇子的街上、在某条船上），记到那个专名地点，并把它收成一个场景。城市、建筑群、整栋楼一般写进「上级」；有戏直接发生在那一级时，那一级也收。
- 名字尽量用原文稳定的专名；别名只收原文能证明是同一个地方的叫法。

### 字段

- **上级**：所在的更大的地点（那户人家、那栋楼、那座城），没有就不写。
- **描述**：时代、室内外、地点类型、标志物、材质颜色和光线。原文没写的部分在「据类型推断：」后面补室内外、空间类型和时代。不写人物动作。
- **出现**：有戏发生在这里的集。

时段、空镜、其他时段的写法见 `design.md`。
