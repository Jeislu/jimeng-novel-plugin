Install Jimeng Drama Plugin for Codex (v1.0.11)

Follow these steps in order to install and verify the jimeng-drama plugin. Do not submit any paid generation jobs during setup or verification.

Step 1: Ensure jimeng-novel CLI is installed

  1. Verify Node.js 18+ (node -v), Python 3.10+ (python3 --version), and check METRICS_LOG_LEVEL=none jimeng-novel --version.
  2. If missing or outdated, install via:
    • macOS / Linux standalone installer:
      (set -o pipefail; curl -fsSL https://jimeng.jianying.com/novel-cli | bash)
  3. Check binary resolution (command -v jimeng-novel on macOS/Linux, where.exe jimeng-novel on Windows) to ensure no stale launcher shadows the installed version.

Step 2: Register Marketplace and Install Plugin

codex plugin marketplace add https://github.com/Jeislu/jimeng-novel-plugin --ref main --json
codex plugin add jimeng-drama@jimeng-plugins --json

If jimeng-plugins already exists, refresh with codex plugin marketplace upgrade jimeng-plugins first.

Step 3: Authorize Jimeng Account

  1. Run METRICS_LOG_LEVEL=none jimeng-novel status.
  2. If not logged in, use jimeng-novel login --help to start non-interactive login, open the official jimeng.jianying.com authorization URL in the browser, share the clickable link, and run the wait command returned by the CLI.

Step 4: Read-Only Verification

METRICS_LOG_LEVEL=none jimeng-novel account get
METRICS_LOG_LEVEL=none jimeng-novel model list --type image

Ask the user to start a new Codex session so the installed plugin skills load cleanly.
