即梦短剧 Codex 插件安装指引

一句话安装（直接发给 Codex）

本页是 jimeng-drama（jimeng-novel CLI 配套插件，v1.0.11）的完整安装与校验说明。将下方指令直接发送给 Codex，即可自动完成 CLI 安装、插件注册与只读验证；整个安装与验证过程不会提交任何扣费生成任务。

请阅读 jeislu.github.io/jimeng-novel-plugin/ 并帮我安装即梦短剧 Codex 插件

1. 安装或更新 jimeng-novel CLI

先检查基础环境：确认已安装 Node.js 18+（node -v）和 Python 3.10+（python3 --version），并执行 METRICS_LOG_LEVEL=none jimeng-novel --version 查看当前状态。若未安装或版本过旧，任选以下一种方式：

跨平台 npm 安装（推荐）

支持 macOS、Linux 与 Windows，需 Node.js 18+：

npm install -g 'https://lf3-static.bytednsdoc.com/obj/eden-cn/psj_slcvu_hupthlyk/ljhwZthlaukjlkulzlp/jimeng-novel/versions/1.0.11/scm-1.0.0.424/general/jimeng-novel-1.0.11-dev.afb84393b7ee.tgz'

macOS / Linux 一键脚本（备选）

自动将散装 Skill 隔离到独立目录，不写入 ~/.agents/skills 和 ~/.codex/skills，避免与 Codex 插件重复加载：

(set -o pipefail; curl -fsSL https://jimeng.jianying.com/novel-cli | bash -s -- --skills-dir "$HOME/.local/share/jimeng-novel/standalone-skills")

安装完成后，检查命令实际指向（macOS / Linux 执行 command -v jimeng-novel，Windows 执行 where.exe jimeng-novel），确认没有被 ~/.local/bin/jimeng-novel 旧入口遮蔽，再确认 METRICS_LOG_LEVEL=none jimeng-novel --version 正常输出版本号。

2. 注册插件市场并安装插件

通过 Codex CLI 添加插件市场并安装 jimeng-drama：

codex plugin marketplace add https://github.com/Jeislu/jimeng-novel-plugin --ref main --json
codex plugin add jimeng-drama@jimeng-plugins --json

如果本机之前已注册过 jimeng-plugins，先执行 codex plugin marketplace upgrade jimeng-plugins 刷新市场，再重新安装插件。

清理旧安装器的散装 Skill 软链接（防重复加载）

如果你此前直接运行过一键安装脚本，执行下方命令可安全移除 ~/.agents/skills 与 $CODEX_HOME/skills 中指向 ~/.local/share/jimeng-novel/releases/ 的软链接，绝不会触碰用户自建目录：

python3 -c 'import os; from pathlib import Path; rel = (Path.home() / ".local/share/jimeng-novel/releases").resolve(); dirs = [Path.home() / ".agents/skills", Path(os.environ.get("CODEX_HOME", str(Path.home() / ".codex"))) / "skills"]; [p.unlink() for d in dirs for n in ("jimeng-drama", "jimeng-short-drama") for p in (d / n,) if p.is_symlink() and p.resolve().name == n and p.resolve().parent.name == "skills" and p.resolve().parent.parent.parent == rel]'

3. 授权即梦账号

  1. 执行 METRICS_LOG_LEVEL=none jimeng-novel status 查看当前授权状态；若已登录，直接跳过本步进入第 4 步。
  2. 若未登录，先查看 jimeng-novel login --help 发起非交互式登录，取得官方授权链接（jimeng.jianying.com）。在浏览器中打开并向用户发送可点击链接，随后执行 CLI 返回的等待命令直至授权完成。

4. 零扣费只读验证

运行以下只读命令核对账号信息与可用模型列表（不会发起任何生成或扣费操作）：

METRICS_LOG_LEVEL=none jimeng-novel account get
METRICS_LOG_LEVEL=none jimeng-novel model list --type image
验证通过后即可告知用户安装完成，并提醒用户新建一个 Codex 对话，让 jimeng-drama 插件 Skill 正式生效。

5. 新建对话即可开始创作

安装完成并开启新会话后，可以直接发送下面任意一句试试：

  • 在即梦短剧画布新建一个短剧项目，帮我写第 1 集设定与剧本
  • 查看当前即梦账号积分余额和可用图片、视频模型
  • 根据已有分镜生成角色设定图、视频片段并合成为成片
